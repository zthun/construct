# Document Variables

Document variables and constants exported from a module. Summarize what each
value represents, including units or context where they help readers interpret
it.

## Examples

```ts
/**
 * The number of bytes in a kibibyte (1024).
 */
export const BYTES_PER_KIB = 1024;

/**
 * The number of milliseconds in 30 seconds.
 */
export const THIRTY_SECONDS_IN_MILLISECONDS = 30_000;
```
